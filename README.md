# EasyJam

발달장애인 음악치료 세션을 위한 실시간 웹 합주 도구입니다.
참여자는 각자 기기에서 악기를 고르고, 치료사는 진행자 화면에서 반주와 연주 방식을 조작합니다.
어떤 건반이나 패드를 눌러도 지금 흐르는 코드에 어울리는 소리가 나도록 설계되어, 악기를 배운 적이 없어도 합주에 참여할 수 있습니다.

*EasyJam is a browser-based ensemble tool for music-therapy sessions with people with developmental disabilities. Every input is mapped to notes that fit the current chord, a therapist console controls the shared backing track and turn-taking, and all devices stay on the same beat through a server-synchronised clock.*

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

- 진행자(치료사): `http://localhost:8000/host.html` 을 열면 4자리 방 번호와 참여자 접속 주소가 표시됩니다.
- 참여자: 같은 Wi-Fi의 기기에서 그 주소로 들어가 이름을 적고 악기를 고릅니다.
- 방 번호 없이 악기를 고르면 혼자 연습하는 모드로 열립니다.

### 다른 기기에서 카메라를 쓰려면 (HTTPS)

브라우저는 `localhost`가 아닌 주소에서는 HTTPS일 때만 카메라를 허용합니다.
타악기의 "머리 움직임으로 연주하기"를 다른 기기에서 쓰려면 인증서를 만든 뒤 다시 실행하세요.

```bash
npm run cert
npm start
```

`certificate/` 폴더에 인증서가 있으면 서버가 자동으로 HTTPS로 뜹니다. 직접 만든 인증서라 각 기기에서 처음 한 번 경고를 넘겨야 합니다.

환경 변수: `PORT`(기본 8000), `HOST`(기본 0.0.0.0), `SSL_KEY`, `SSL_CERT`.

## 악기

| 악기 | 입력 | 소리 |
| --- | --- | --- |
| 피아노 | 화면 건반, 키보드 1~9 / A~L, MIDI | 지금 코드의 화음 (건반 위치에 따라 보이싱 3종) |
| 색소폰 | 누르기·스치기, 마우스 올리기, 키보드 1~9, MIDI | 지금 코드에 어울리는 스케일 음. 코드 구성음은 크게 표시 |
| 타악기 1 (셰이커·트라이앵글) | 터치, ← →, 카메라(머리 좌우 움직임) | 왼쪽·오른쪽 악기 |
| 타악기 2 (콩가·탬버린) | 위와 같음 | 위와 같음 |

## 치료 세션을 위한 기능

- **도움 단계 (쉬움 / 보통 / 도전)**: 참여자마다 진행자가 원격으로 바꿉니다.
  - 쉬움: 피아노는 한 번 누르면 끝까지 울리고, 색소폰은 코드 구성음 패드만 보이고, 타악기는 카메라 인식 영역이 넓어집니다.
  - 쉬움·보통: 조금 일찍 누른 음을 가장 가까운 8분음표에 맞춰 냅니다(박자 보정).
  - 도전: 박자 보정 없이 누른 순간 그대로 소리가 납니다.
- **차례 연주**: "모두 함께", 한 사람만 연주하는 "솔로", 정해진 마디마다 차례가 넘어가는 "돌아가며". 차례가 아닌 참여자의 화면은 흐려지고 "○○의 연주를 들어요", 차례 직전에는 "곧 내 차례예요"가 표시됩니다.
- **따라 치기**: 진행자가 고르거나 직접 만든 한 마디 리듬이 시범으로 울리고(듣기), 다음 마디에 참여자가 따라 칩니다. 화면 위 8칸 띠가 쳐야 할 곳과 실제로 친 곳을 보여 주고, 어떤 음을 눌렀는지와 상관없이 리듬만 채점해 참여자별 정확도를 기록합니다.
- **재즈처럼 들리게 하는 규칙** (`public/js/core/jazz.js`): 피아노는 코드가 바뀌기 직전 엇박에 누르면 다음 코드를 미리 내고(당겨 치기), 건반을 누르고 있으면 코드가 바뀔 때 새 코드로 이어집니다. 타악기는 2·4박은 세게, 엇박은 여리게 나고 칠 때마다 음색이 조금씩 달라지며, 쉬움 단계에서는 누르고 있으면 박자에 맞춰 계속 울립니다.
- **멈춤 놀이**: 진행자가 음악을 일시정지하면 모든 악기가 함께 멈추고 ✋ 표시가 나옵니다.
- **빠르기 조절**: 70~110%. 음높이는 그대로 유지됩니다.
- **차분한 화면**: 반짝임과 움직임을 끄고 색 대비를 낮춥니다. 기기의 "동작 줄이기" 설정도 따릅니다.
- **칭찬 보내기**: 진행자가 특정 참여자 화면에 👏를 띄웁니다.
- **세션 기록**: 참여자별 연주 횟수, 박자에 맞은 비율, 평균 박자 오차, 10초 단위 참여도 타임라인을 CSV로 내려받습니다.
- **반주 출력 선택**: 같은 공간이면 진행자 기기에서만, 이어폰을 쓰거나 떨어져 있으면 모든 기기에서 동기화해 재생합니다.

## 구조

```
server/
  server.js      HTTP(S) + WebSocket 연결, 죽은 연결 정리
  rooms.js       방·참여자·트랜스포트·통계 (네트워크와 분리된 순수 로직)
  static.js      정적 파일 (경로 탈출 차단, Range, ETag)
public/
  index.html     첫 화면
  host.html      진행자 화면
  piano.html / saxophone.html / percussion.html
  js/core/
    song.js      곡 데이터와 타임라인 계산 (모든 악기가 공유)
    net.js       자동 재접속 + 시계 동기화
    transport.js 곡 위치 계산, 반주 재생과 어긋남 보정
    audio.js     샘플 미리 디코딩, 예약 재생, 리미터
    session.js   악기 화면 공통 (접속, 차례 안내, 설정 적용)
  easyjazz/      이전 솔로 버전 (EasyJazz)
assets/          소리와 이미지
test/            단위 테스트
legacy/          2024년 버전 원본 (참고용 보관)
```

### 박자가 맞는 원리

1. 각 기기는 서버와 ping/pong을 주고받아 서버 시계와의 차이를 추정합니다. 왕복 시간이 가장 짧았던 측정값을 씁니다.
2. 서버는 재생 상태를 `{ playing, pos, at, rate }` 로 방송합니다. 재생 중 위치는 `pos + (서버시각 - at) × rate` 입니다.
3. 코드, 박자 격자, 차례는 모두 이 위치에서 계산합니다. 타이머를 쌓아 가지 않으므로 5분 내내 연주해도 밀리지 않고, 중간에 들어오거나 새로고침한 기기도 바로 같은 위치를 얻습니다.
4. 반주를 재생하는 기기는 실제 재생 위치와 계산 위치를 0.25초마다 비교해, 35ms 넘게 어긋나면 재생 속도를 3% 조절하고 200ms 넘게 어긋나면 바로 이동합니다.

## 2024년 버전에서 바뀐 점

| 예전 | 지금 |
| --- | --- |
| WebSocket 서버가 메시지를 받기만 하고 아무 일도 하지 않음 | 방, 역할, 공유 트랜스포트, 통계를 다루는 프로토콜 |
| 기기마다 반주를 따로 재생해 서로 어긋남 | 서버 시계 기준으로 모든 기기가 같은 곡 위치를 계산 |
| 코드 진행을 `setTimeout`으로 넘겨 시간이 갈수록 밀림 | 재생 위치에서 코드를 계산 |
| 색소폰은 모든 코드를 4박으로 넘겨 2박 코드에서 피아노와 어긋남 | 악기 공통 곡 데이터 한 벌 |
| 색소폰 스케일에 음원이 없는 음(D♭5)이 있어 소리가 안 남 | 스케일과 음원 파일을 테스트로 검사 |
| 반주가 끝나면 인트로부터 반복되는데 코드 계산은 인트로를 무시 | 곡 끝에서 정지 |
| `<audio>` 태그 재생이라 반응이 늦고 연타가 씹힘 | Web Audio로 미리 디코딩, 예약 재생 |
| 소리가 ogg라 iPad Safari에서 재생되지 않음, 반주는 54MB WAV | 모두 mp3 (반주 7MB) |
| 자세 인식이 한 번 실패하면 영영 멈춤, 카메라가 없으면 연주 불가 | 실패해도 계속 시도, 터치·키보드로 항상 연주 가능 |
| TensorFlow.js를 버전 지정 없이 불러옴 | 버전 고정, 카메라를 켤 때만 불러옴 |
| 서버가 요청 경로를 그대로 파일 경로에 붙임 | 폴더 밖 접근 차단 |
| 창을 벗어나면 누르던 음이 계속 울림 | 포커스를 잃으면 모든 음 해제 |
| 연결이 끊기면 그대로 멈춤 | 자동 재접속, 같은 참여자로 복귀, 기록 유지 |

## 알려진 한계

- 방과 기록은 서버 메모리에만 있습니다. 서버를 다시 시작하면 기록이 사라지므로 세션이 끝나면 CSV를 내려받으세요.
- 박자 통계는 기기의 터치·오디오 지연과 네트워크 시계 오차를 포함합니다. 참고용 지표입니다.
- 카메라 연주는 인터넷에서 인식 모델을 내려받습니다. 인터넷이 없는 곳에서는 터치·키보드·MIDI로 연주합니다.
- 곡은 Sunny 한 곡입니다. 곡을 추가하려면 `public/js/core/song.js` 에 코드 진행과 음원을 넣습니다.
